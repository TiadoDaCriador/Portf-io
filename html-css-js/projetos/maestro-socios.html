maestro sócios.

Tipo
App móvel
Contexto
Estágio · MUsa Software
Estado
Publicada no Google Play
Tecnologias
  • Ionic Angular
  • Capacitor
  • REST API (JWT)
  • Firebase
  • Sentry

App de gestão de sócios para associações musicais. Tem login biométrico, cartão de sócio com QR code, notificações push, três idiomas (PT, EN e ES) e eliminação de conta, por causa do RGPD. Liga-se a uma API REST própria.

Fi-la durante o estágio de 4 meses na MUsa Software. A API a que se liga é a da própria MUsa.

o que faz.

  • Login biométrico
  • Cartão de sócio em QR code
  • Notificações push
  • API REST com autenticação JWT
  • Português, inglês e espanhol
  • Eliminação de conta (RGPD)
