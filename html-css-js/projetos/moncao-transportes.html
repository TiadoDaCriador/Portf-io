monção transportes.

Tipo
App web
Contexto
Projeto pessoal
Estado
Não publicado
Tecnologias
  • React
  • TypeScript
  • Node.js
  • PostgreSQL / PostGIS

App para consultar o transporte público do concelho de Monção: linhas, paragens, horários, mapa e planeador de rotas com transbordo.

Os horários seguem o modelo GTFS. Os veículos no mapa são simulados, porque não há GPS real. É um projeto pessoal e nunca foi publicado.

o que faz.

  • Linhas, paragens e horários
  • Horários no modelo GTFS
  • Mapa da rede com veículos simulados
  • Planeador de rotas com transbordo
