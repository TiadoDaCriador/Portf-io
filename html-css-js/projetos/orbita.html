órbita.

Tipo
App web
Contexto
Projeto pessoal
Estado
Não publicado
Tecnologias
  • NestJS
  • Prisma
  • PostgreSQL
  • Next.js
  • Docker

Plataforma para gerir associações e clubes: sócios, quotas, eventos e conteúdo. Várias empresas partilham a mesma base de dados e cada uma vê só os seus dados, porque cada registo leva o identificador da empresa.

O back-office é uma app Next.js e a API é NestJS com Prisma e PostgreSQL. A mesma API serve também uma app de sócios. É um projeto pessoal e nunca foi publicado. Os ecrãs abaixo usam dados de demonstração.

o que faz.

  • Várias empresas na mesma base de dados, com dados isolados
  • Sócios, quotas e pagamentos
  • Eventos com inscrições e check-in
  • Conteúdo: artigos, comunicados e documentos
  • Utilizadores com perfis de admin, membro e leitor
